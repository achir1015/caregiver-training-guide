# 照顧服務員訓練指引｜章節閱讀與查詢程式

把《照顧服務員訓練指引》（掃描 PDF）轉成可依**章節大綱**閱讀、用**關鍵字**查詢全文的網頁，適合照顧服務員在實務現場快速查找照顧技術、常見情境的處理原則與工作方法。

> **本 repo 只放程式，不含書籍內容。** 書籍有版權，PDF、OCR 結果與轉出的資料檔都列在 `.gitignore`，只留在自己的電腦或裝置上。

## 功能

- **章節大綱**：左側依「章 → 節 → 小標」展開，含各章導讀與附錄。
- **關鍵字查詢**：空白分隔多個關鍵字＝同一段落需同時包含；可限定章節；結果依章節分組並標示原書頁碼。
- **照顧技術操作**：首頁列出 46 項技術（10-1 測量耳溫 … 18-2 哈姆立克法），點選直接跳到步驟與說明。
- **跳到原書頁碼**、常用關鍵字按鈕、字級調整、深色模式；按 `/` 聚焦搜尋框。
- **手機／平板**：響應式版面；網址列小圖示、主畫面捷徑圖示（Android 會出現「安裝」按鈕，iPhone 用 Safari「分享 → 加入主畫面」）；開過一次即可離線使用。

## 使用方式

### 1. 在電腦上產生資料（需要原書 PDF）

把 `照顧服務員訓練指引.pdf` 放在 repo 根目錄，然後：

```bash
pip install pymupdf winocr pillow
python tools/ocr.py
python tools/build.py
```

- `tools/ocr.py`：用 Windows 10/11 內建的繁體中文 OCR 辨識每張書頁截圖，產生 `ocr.json`（約 25 分鐘，可中斷後續跑）。
- `tools/build.py`：依目錄切成章節段落，產生
  - `data.js`：本機直接開啟 `index.html` 時使用（段落旁頁碼可開啟 PDF 原頁）
  - `download/照顧服務員訓練指引-資料.json`：給網站「匯入資料」用
  - `download/照顧服務員訓練指引.html`：單檔版（資料內嵌，一個檔案即可離線開啟）

### 2. 閱讀

網站：https://achir1015.github.io/caregiver-training-guide/

- **電腦**：直接用瀏覽器開啟 `index.html`。
- **手機／平板**：開啟 GitHub Pages 網址，第一次使用時依畫面「步驟 1」到 Google 雲端硬碟下載 `照顧服務員訓練指引-資料.json`，再「步驟 2」匯入（雲端硬碟網址設定在 `index.html` 的 `DATA_URL`），資料只存在該裝置的瀏覽器（IndexedDB），不會上傳。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 閱讀與查詢介面（單一檔案，無外部相依） |
| `manifest.webmanifest`、`sw.js`、`icons/`、`favicon.ico` | 網址列圖示、主畫面捷徑、安裝與離線快取 |
| `tools/ocr.py` | 掃描 PDF → `ocr.json`（Windows OCR） |
| `tools/build.py` | `ocr.json` → 章節資料與單檔版；目錄與技術清單寫在檔案內的 `TOC`、`SKILLS` |
| `tools/make_icons.py` | 產生網站圖示 |

## 說明

- 內容由書頁影像 OCR 轉出，個別字詞、數字與表格可能有誤，請以原書為準。
- 原 PDF 缺少原書第 406–409 頁與第 710 頁以後的截圖，這些頁面沒有文字。
- 書籍內容版權屬原出版社及作者，本程式僅供個人學習查詢使用。
